# 🧠 Memory Card Flip Game

An interactive Memory Card Flip Game built using HTML, CSS, and JavaScript.

This game tests the player's memory by requiring them to match pairs of cards with the least number of moves.

🔗 **Live Demo:** [https://your-netlify-link.netlify.app](https://memory-game-av.netlify.app/)

---

## 🚀 Features

- Card flip animation
- Match detection logic
- Move counter
- Restart game option
- Win popup message
- Responsive design

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
