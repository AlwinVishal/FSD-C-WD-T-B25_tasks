# React Cart Application

## Overview
This is a React-based e-commerce cart application that allows users to browse products, add them to a cart, and manage their selections.

## Features
- Fetch products from Fake Store API
- Display products in a responsive grid layout
- Add and remove items from cart
- Increase/decrease item quantity
- Dynamic total price calculation
- 10% discount on total price
- Navigation using React Router
- Cart item count displayed in Navbar

## Tech Stack
- ReactJS
- React Router
- Tailwind CSS
- JavaScript

## Pages
- Products Page
- Cart Page

## API Used
https://fakestoreapi.com/

## Deployment
