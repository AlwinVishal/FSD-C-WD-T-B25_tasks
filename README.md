# Income Expense Calculator

## Project Description

The Income Expense Calculator is a simple web application built using HTML, Tailwind CSS, and JavaScript. It allows users to track their income and expenses, manage entries, and view their financial summary.

The application supports full CRUD operations and stores data in local storage so that information persists even after refreshing the page.

---

## Features

* Add new income and expense entries with description and amount
* Edit existing transactions
* Delete transactions
* Filter transactions by:

  * All
  * Income
  * Expense
* View total income, total expense, and available balance
* Reset input fields
* Data persistence using localStorage
* Responsive user interface using Tailwind CSS

---

## Technologies Used

* HTML
* Tailwind CSS (via CDN)
* JavaScript
* Browser Local Storage

---

## How to Use

1. Enter a description for the transaction
2. Enter the amount
3. Select the type (income or expense)
4. Click "Submit" to add the entry
5. Use the Edit button to modify an entry
6. Use the Delete button to remove an entry
7. Use the radio buttons to filter transactions
8. View totals in the summary section

---

## Project Structure

* index.html – Main structure of the application
* script.js – Handles all logic including CRUD operations, filtering, and local storage
